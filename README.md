## 🚀 Featured Projects

### ⚡ [EV Mobility Platform](https://github.com/ishant-rathore/EV-Mobility-Platform)
A modular EV-mobility project exploring journey and energy planning, charging-station recommendations, charging and parking reservations, and IoT-connected parking workflows.

### 📄 [SnapData](https://github.com/ishant-rathore/SnapData)
An Android document-processing application with Kotlin, Jetpack Compose, OCR and AI processing modules, local persistence, document review screens, and export components. It is under active development; see the repository's CI status before relying on a release build.

### 🧭 [AI Career Navigation Platform](https://github.com/ishant-rathore/AI-powered-Career-Navigation-and--Roadmap-Platform)
A career-navigation project exploring career assessments, skill-gap analysis, and structured learning roadmaps with web and AI/ML components documented in the repository.

### 🧠 [MindMatrix.ai](https://github.com/ishant-rathore/MindMatrix.ai)
An AI-assisted wellbeing companion prototype with text and voice check-ins, analysis history, chat interfaces, and multilingual service logic. It is not a medical diagnostic tool.

### 🗺️ [College Website & Roadmap](https://github.com/ishant-rathore/Pillai-College-Website-with-Roadmap-Features-)
A student-focused web project exploring college information and roadmap-oriented features.
